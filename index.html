Topo Survey Plotter

Import survey CSV points, classify field codes, and plot point symbols or connected linework.

Code Library

Codes can be exact, like BM, or prefixes, like RE* for RE1, RE2, RE3.

Plot Settings

Plot Instructions

Use one instruction per line. Examples: AREA EP closes all EP points as a boundary area. SYMBOL BH BOREHOLE plots BH points with a borehole symbol.

CSV Format

Accepted columns: PointNo, Easting, Northing, Elevation, Code. Headerless files in that order also work.
